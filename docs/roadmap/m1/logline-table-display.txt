  📋 Implementation Plan for /log/lines Page

  Overview

  Create a new page at /log/lines that allows querying and displaying log lines with filtering capabilities, showing type-specific fields based on the LogLineDto subclass.

  ---
  Phase 1: Type Definitions & API Client

  1.1 Update API Client Types (lib/api-client.ts)

  - Add event type enums: GoogleDriveEvent, GoogleMailEvent, GoogleTasksEvent, GoogleDeviceEvent
  - Add document type enum: GoogleDriveDocumentType
  - Create extended LogLine DTOs:
    - GoogleDriveEventLogLineDto extends LogLineDto
    - GoogleMailEventLogLineDto extends LogLineDto
    - GoogleTasksEventLogLineDto extends LogLineDto
    - GoogleMobileDeviceEventLogLineDto extends LogLineDto
  - Create union type: ExtendedLogLineDto = GoogleDriveEventLogLineDto | GoogleMailEventLogLineDto | GoogleTasksEventLogLineDto | GoogleMobileDeviceEventLogLineDto

  1.2 Add API Client Methods (lib/api-client.ts)

  Add 9 new query methods:
  - getLogLinesByLogId(logId: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByActor(actor: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByOwner(owner: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByEvent(eventType: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByDomain(domain: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByIp(ipAddress: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByDateRange(start: string, end: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesByUser(user: string): Promise<ExtendedLogLineDto[]>
  - getLogLinesSharingDetection(owner: string): Promise<ExtendedLogLineDto[]>

  ---
  Phase 2: UI Components

  2.1 Create Query Filter Component (components/log/LogLinesQueryPanel.tsx)

  - Tabbed interface or dropdown to select query type:
    - By Actor
    - By Owner
    - By Event Type
    - By Domain
    - By IP Address
    - By Date Range
    - By User
    - Sharing Detection
    - By Log ID
  - Input fields for selected query type
  - "Search" button to execute query
  - Clear/Reset functionality

  2.2 Create Enhanced Table Component (components/log/LogLinesQueryTable.tsx)

  Features:
  - Display all LogLineDto base fields as columns:
    - Type (badge with color)
    - Date
    - Event Type
    - Actor
    - Owner
    - Target
    - Domain
    - IP Address
  - Color entire row based on LogLineType
  - Add "Details" column that shows type-specific fields
  - Expandable row or modal to show full details of type-specific fields
  - Pagination support (client-side initially)
  - Sort by column functionality
  - Export to CSV/JSON functionality

  2.3 Create Type-Specific Detail Views (components/log/details/)

  Create 4 detail components for each subclass:
  - GoogleDriveDetails.tsx - Shows all GoogleDriveEventLogLineDto fields
  - GoogleMailDetails.tsx - Shows all GoogleMailEventLogLineDto fields
  - GoogleTasksDetails.tsx - Shows all GoogleTasksEventLogLineDto fields
  - GoogleDeviceDetails.tsx - Shows all GoogleMobileDeviceEventLogLineDto fields

  Each should display fields in a clean, organized grid layout.
