  How to Use

  Creating Activity Events:

  1. Navigate to Activity Events from the sidebar
  2. Click Create New Activity Event
  3. Fill in name and description
  4. Select multiple Role Titles from the dropdown
  5. Select multiple Log Line Types from the dropdown
  6. Click Create Activity Event

  Running Analysis:

  1. Navigate to Analysis from the sidebar
  2. Select a Company from the dropdown
  3. Select one or more Activity Events using checkboxes
  4. Click Analyze
  5. View the results showing:
    - Matching SOP steps that match the selected activity events' role titles
    - Matching log lines that match the selected activity events' log line types
